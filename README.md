# ClassRecordPH

The class record, attendance and DepEd school forms of Filipino teachers, on their own computer, with or without internet.

## For Windows 10 or 11

**[Download ClassRecordPH](https://github.com/ClassRecordPH/releases/releases/latest/download/ClassRecordPH-Setup.exe)** — always the newest version. One file of about 1.2 GB: ClassRecordPH and its offline AI are both inside it, it installs with no internet, and it can be passed to other teachers on a USB stick.

## Updates

A computer that has ClassRecordPH updates itself when it is opened with internet. An update never changes the class records.

ClassRecordPH is made by ADSph — Advantage Digital Systems Philippines.
