# ClassRecordPH

The class record, attendance and DepEd school forms of Filipino teachers, on their own computer, with or without internet.

## For Windows 10 or 11

**[Download ClassRecordPH for Windows](https://github.com/ClassRecordPH/releases/releases/latest/download/ClassRecordPH-Setup.exe)** — always the newest version. One file of about 1.2 GB: ClassRecordPH and its offline AI are both inside it, it installs with no internet, and it can be passed to other teachers on a USB stick.

## For Mac

**[Download ClassRecordPH for Mac](https://github.com/ClassRecordPH/releases/releases/latest/download/ClassRecordPH-Mac.dmg)** — for Macs with Apple's own chips (2020 and later), about 140 MB. For an older Intel Mac: **[ClassRecordPH for Intel Macs](https://github.com/ClassRecordPH/releases/releases/latest/download/ClassRecordPH-Mac-Intel.dmg)**.

The offline AI on a Mac is one more file, opened once: **[ClassRecordPH Offline AI](https://github.com/ClassRecordPH/releases/releases/latest/download/ClassRecordPH-Offline-AI.crphai)** (1.1 GB). Double-click it after ClassRecordPH is installed, and the AI is added.

## Updates

A Windows computer that has ClassRecordPH updates itself when it is opened with internet. An update never changes the class records. On a Mac, download the newest version from this page.

ClassRecordPH is made by ADSph — Advantage Digital Systems Philippines.
